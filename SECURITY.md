# Security policy

## Supported version

Security fixes are applied to the latest commit on `main` and then released to the hosted application. Older commits and forks are not supported.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/dantheman24mac/teachnotes/security/advisories/new). Do not open a public issue, discussion or pull request containing exploit details, credentials, personal data or production configuration.

Include the affected route or component, reproduction steps, expected impact and any suggested remediation. You should receive an acknowledgement within seven days. Please allow reasonable time for investigation and a coordinated fix before disclosure.

## Scope

Useful reports include authentication or approval bypasses, Row Level Security failures, cross-workspace data access, stored or reflected script injection, private invoice disclosure, secret exposure and unsafe deployment behavior.

The synthetic demo contains no production data or credentials. Fictional records in the demo are not a privacy incident.
